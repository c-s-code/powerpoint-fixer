# powerpoint-fixer
A VBA script for windows desktop PowerPoint. Release under GNU GPL v2.0.

## Download & Use

- Download and unzip most recent Release archive **or** download PPT_MultiTool.bas directly
- Open VBA editor from PowerPoint project (ALT + F11)
- File > Import file > select the PPT_MultiTool.bas
- Run using play button:
  - SlideChecker - cleanup, check, fix, and export
  - Export - export-only

## Features:

- Cleanup
  - move audio or video off visible page if required
- Check and fix:
  - transition timings vs narration duration
  - slides containing multiple media files
  - remove animated slide transitions
- Summarise:
  - total presentation duration
  - number of slides & issues
  - avg duration per slide
- Export:
  - to chosen folder, same name as .pptx file
  - mp4 at 720p
